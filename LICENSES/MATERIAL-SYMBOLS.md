# Material Symbols Outlined

This project includes the **Material Symbols Outlined** icon font.

- Source: <https://fonts.google.com/icons>
- Font file: `client/public/fonts/material-symbols-outlined.v2.woff2`
- License: **Apache License 2.0** — <https://www.apache.org/licenses/LICENSE-2.0>
  (testo completo in `LICENSES/Apache-2.0.txt`)
- Copyright: Google LLC

The distributed file is a self-hosted subset built from the icons used by the
client, downloaded from Google Fonts. Icons are rendered as ligatures through the
`material-symbols-outlined` CSS class; no external font CDN is used at runtime.

The subset is generated by `scripts/material-symbols.mjs`: `npm run icons:build`
downloads it from Google Fonts and `npm run icons:check` verifies that every
literal icon referenced by the client is present in the script's `ICONS` list.
The download uses Google Fonts' `icon_names` parameter, so only the glyphs of the
listed icons are kept in the self-hosted file.
