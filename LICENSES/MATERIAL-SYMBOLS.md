# Material Symbols Outlined

This project includes the **Material Symbols Outlined** icon font.

- Source: <https://fonts.google.com/icons>
- Font file: `client/public/fonts/material-symbols-outlined.v1.woff2`
- License: **Apache License 2.0** — <https://www.apache.org/licenses/LICENSE-2.0>
  (testo completo in `LICENSES/Apache-2.0.txt`)
- Copyright: Google LLC

The distributed file is a subset containing only the icons used by the client,
downloaded from Google Fonts. Icons are rendered as ligatures through the
`material-symbols-outlined` CSS class; no external font CDN is used at runtime.
